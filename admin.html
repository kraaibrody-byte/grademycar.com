3. What's real vs. best-effort here

Real, reads/writes your actual data: Users list, credit balances, lifetime spend/searches (from the fields your own signup code and Cloud Functions already write), Roadmap Flags, and the Reliability Data count (fetched live from GitHub).

Real, confirmed against your source: the "Grant unlimited" buttons write to unlimitedAccess/adminGrant on the user record — verified directly against your deployed checkReportAccess function, which scans every entry under unlimitedAccess for one that's active and unexpired.

Not included: per-bundle Stripe revenue breakdown and "which listing site" activity — neither is logged anywhere in your current code, so building them would mean adding logging first (e.g. having content.js call window.saveVehicleSearch with a site field, or reading Stripe's API from a Cloud Function). Happy to wire those up if useful.
